# 🚀 README – Configuração de Ambiente Back-end com Node.js e TypeScript

## 📝 Descrição

Esta atividade teve como objetivo configurar um ambiente de desenvolvimento back-end utilizando **Node.js**, **TypeScript** e **Git**, preparando a estrutura necessária para criação e execução de aplicações TypeScript em um projeto Node.js.

Durante o desenvolvimento, foram realizados os processos de inicialização do projeto, configuração dos arquivos essenciais, instalação das dependências necessárias, criação dos scripts de execução e versionamento do projeto em um repositório remoto no GitHub.

---

## 🎯 Objetivos

* ✅ Configurar um ambiente de desenvolvimento back-end.

* ✅ Inicializar um projeto utilizando **Node.js**.

* ✅ Instalar e configurar o **TypeScript**.

* ✅ Configurar os arquivos `package.json`, `tsconfig.json` e `.gitignore`.

* ✅ Executar aplicações TypeScript utilizando o comando `npm run dev`.

* ✅ Utilizar **Git** e **GitHub** para versionamento do projeto.

* ✅ Documentar a estrutura e configuração do ambiente de desenvolvimento.

---

## 📁 Estrutura do Projeto

O ambiente foi organizado com a estrutura básica de um projeto Node.js com suporte a TypeScript, contendo os principais arquivos de configuração necessários para desenvolvimento e execução da aplicação.

Arquivos principais:

* 📄 `package.json` – Gerenciamento do projeto, dependências e scripts.

* 📄 `tsconfig.json` – Configuração do compilador TypeScript.

* 📄 `.gitignore` – Arquivos e pastas ignorados pelo Git.

* 📁 `src/` – Diretório destinado aos arquivos-fonte da aplicação.

* 📄 `app.ts` – Arquivo principal da aplicação TypeScript.

---

## ⚙️ Configurações Realizadas

Durante a atividade foram realizadas as seguintes etapas:

1. 📦 Inicialização do projeto Node.js.

2. 📘 Instalação do TypeScript e das dependências de desenvolvimento.

3. ⚙️ Criação do arquivo de configuração do TypeScript.

4. 🚀 Configuração do script de desenvolvimento para execução com `npm run dev`.

5. 🌿 Inicialização do repositório Git.

6. ☁️ Criação e envio do projeto para um repositório remoto no GitHub.

---

## ▶️ Execução do Projeto

Após a configuração do ambiente, a aplicação pode ser executada utilizando o script de desenvolvimento definido no projeto.

Comandos utilizados durante a atividade:

```
npm install
npm run dev
```

Esses comandos instalam as dependências do projeto e executam a aplicação TypeScript no ambiente de desenvolvimento.

O projeto foi versionado utilizando Git e publicado em um repositório remoto no GitHub, garantindo organização, controle de versões e documentação do ambiente configurado.
